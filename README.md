# 现代诗语义结构可视化
使用 p5.js 交互工具，把带语义标注（本项目作者进行的）的诗歌意象及诗歌意义结构渲染为 3D 坐标空间与关系网络，支持单诗结构分析和多诗平行对比（平行坐标 / 函数曲线 / 相关系数 / 结构指纹）。
下面是重写后的 README。方法和作者身份放前面，工具放后面。

## 方法

### 核心假设

一首诗的“意义结构”可以被近似地表示为：

1. **一组意象**（每一个是一个语义单位）
2. **意象之间的坐标关系**（在若干语义维度上的位置）
3. **意象之间的关系**（承续、对照、隐喻、互文……）

### 两种几何

**坐标几何**：每个意象是一个在 N 维语义空间里的点。三条轴分别是：
- 内向 ↔ 外向（指向内心还是外部世界）
- 静 ↔ 动（意象本身是静止还是运动）
- 具象 ↔ 抽象（能否被眼睛直接看见）

适合回答“这首诗整体偏哪一端”。

**网络几何**：每个意象是网络的一个节点，边代表某种关系。适合回答“哪个意象是枢纽、哪些意象相互呼应”。

这两种几何不是互相替代，而是回答不同问题——所以工具两两出现。

### 三种编码

- **位置** = 意象的语义坐标
- **颜色** = 意象属于哪首诗 / 哪类关系
- **亮度变化** = 当前“脚步”走到哪里

## 工具

### 1. 脚步 ·几何立体图
`脚步几何立体图.html`

把《脚步》（杨牧）里的 24 个意象放到一个三维坐标里。每个意象是一个点，脚步（一个发光的动点）按原诗顺序遍历它们，走过的轨迹亮起。可以按 `1–6` 单看某条维度、按 `H` 隐藏所有维度线。

### 2. 脚步 · 意象纤维网
`脚步意象纤维网络.html`

同一首诗的另一种画法：不放在坐标里，而是用力导向布局，让每个意象变成一个网络节点，用不同颜色和线型的边表示六种关系：承续、隐喻、对照、感官、互文、空间共在。点击任意词，高亮它的所有关系；点击图例，只看某一类边。

### 3. 孤独国 · 意象纤维网
`孤独国意象纤维网络.html`

同样的纤维网方法，用在周梦蝶《孤独国》。两个特殊锚点：
- **雪峰场景锚**（“负雪山峰”）：连向所有在这首诗里“在雪峰上被看见”的意象。
- **佛家底色锚**（琥珀金色的“佛家”）：从被佛家语汇渗透的意象汇聚向它。

### 4. 故事 · 潮水自指
`故事意象纤维网络.html`

《故事》（杨牧）的纤维网，构图完全不同：外围是一个环，上方是核心意象和两个更高阶的词。核心意象之间用虚线画出自指弧——“回旋的曲律”和“缠绵的论述”同时指向“潮水”，呼应原诗“潮水是这首诗”的回环结构。

### 5. 四诗对比 · 脚步 / 孤独国 / 崖上 / 水仙花
`杨牧周梦蝶四首诗对比.html`

把四首诗放在同一个坐标系里做多维度对比。左侧 3D 场景，右侧四块面板：

- **平行坐标图**：每个意象一条折线，看四首诗的意象在三条维度上各自收束还是炸开。
- **函数视图**：X 轴是诗进程，Y 轴是维度值，把每首诗画成三条走势曲线。底部“变化速度带”用颜色表示情绪变化的快慢。
- **相关性表**：两两之间算皮尔逊相关系数，给出内向 / 动静 / 具抽 / 综合四组相似度。
- **指纹表**：整首诗的统计量——平均内向、平均动静、平均具抽、聚散度、缠绕度。

### 6. 其他局部实验
`脚步力导向图.html` 是纤维网的早期版本，用来调试图布局算法。保留作为过程记录。

## 技术

- **p5.js**（WEBGL 模式）负责 3D 场景。
- **HTML + CSS + JS 混合投影**：3D 坐标不直接渲染文字（会变形），而是通过 `uMVMatrix` 和 `uPMatrix` 手动投影到屏幕坐标，再用 HTML div 精确定位标签。这样文字永远清晰、不随视角翻转。
- **力导向布局**：在 p5 里自实现，只对 YZ 平面迭代，X 轴保留诗句顺序。
- **信息论量**：四诗对比里的相关性用皮尔逊相关系数；走势图上的“变化速度带”用局部差分。
- **无依赖**：每个 HTML 文件独立运行，双击即开。
